Replacement rules

Rules are applied in order before standard proxy URL rewriting. Use literal for ordinary text or URL substitutions; choose regex only when the pattern is a JavaScript regular expression.

Response value scripts

When the upstream response URL matches a rule, read a value from the JSON body, a response header, a form field or a text capture, run the JavaScript with that value, and write the returned value back into the same place.

URL intercept script

When a request URL matches the pattern, the proxy skips the upstream request and runs the JavaScript below. The script can read request.method/path/query/url/headers/cookies/body, and must return a string or an object with status, headers, body and content_type.

Verification service

Optional paid service for authorized standalone Turnstile widgets. Disabled by default. A valid token does not guarantee upstream login.

Provider-only mode starts a paid task immediately for the matched widget. No fake success or forced button enabling. Expiry, reset and removal clear the result without automatic paid retries.

Native-first mode waits 10 seconds; provider-only mode starts immediately. Each page may create one paid task. Failed tasks are not retried automatically. Refreshing can consume another task. The hourly count survives restarts. The browser never submits passwords to 2Captcha.

Compatibility and audit controls

Enabling audit captures textual request and response bodies up to the server-wide limit. Binary or oversized content is kept only as bounded metadata and a sample.
